# This project is intended to be a service where local people can share free period product locations, while also spreading more awareness to the people of Hong Kong.



# For future students:
In the web app's current state, pinning a location and writing a
description for that location works. The client requested that an
account system be put into place, to prevent people from spreading
misinformation. Under each location, a rating and comment system
should be added, which would help the longevity of the app, after many
locations are added. Additionally, try to implement a system where the
web app can grab the user's location, so the pin is automatically on
the right place on the map. The web app could also use an update
with the UI and layout to make things more user-friendly. The
firebase database key is in the history, so it is best if you create a
new one. Remember not to publicly post the key, and make sure you
include a .gitignore. ​​
